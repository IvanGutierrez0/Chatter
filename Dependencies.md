# Dependencies of this project
0. Esp32 Boards Drivers (Available in Arduino IDE as ESP32 by Espressif, https://github.com/espressif/arduino-esp32)
1. AdafruitBusIO (Available in Arduino IDE, https://github.com/adafruit/Adafruit_BusIO)
2. AdafruitGFXLibrary (Available in Arduino IDE, https://github.com/adafruit/adafruit-gfx-library)
3. AdafruitSSD1306Library (Available in https://github.com/adafruit/Adafruit_SSD1306/tree/master)
4. Esp32Time (Available in Arduino IDE, https://github.com/fbiego/ESP32Time)
5. Keypad (Available in https://github.com/Chris--A/Keypad)
6. LoRa (Available in Arduino IDE)
